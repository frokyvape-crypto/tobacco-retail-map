# 수도권 담배소매인 입지 지도

서울·경기·인천 도로마다 가장 가까운 기존 담배소매인까지의 **보행거리**를 계산해, 그 시군구 「담배소매인 지정기준 규칙」의 영업소 간 거리(50m·100m)와 비교한 지도입니다. 카카오맵 위에 지정 가능 / 경계(±20m) / 지정 불가를 색으로 표시합니다.

- 지도: https://frokyvape-crypto.github.io/tobacco-retail-map/
- 인허가 데이터 기준일 2026-10-13, 도로망 OpenStreetMap 2026-10-13
- 이 지도는 후보지를 고르는 참고용입니다. 지정 여부는 관할 시·군·구청의 현장 실측과 심사로 결정됩니다.
